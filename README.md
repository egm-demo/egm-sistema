# ЕГМ — рабочая система (замена Saby TMS и Excel)

## Запуск
1. Дважды щёлкнуть **START_EGM.cmd**. При первом запуске он сам поставит компоненты (нужен Python 3.11+).
2. Откроется браузер с адресом `http://localhost:8000`.
3. Логин `admin`, пароль лежит в файле `data/FIRST_LOGIN.txt`. После входа смените пароль и удалите этот файл.
4. Сотрудники в той же сети открывают `http://<IP этого ПК>:8000`. Если не открывается, разрешите порт 8000 в брандмауэре Windows.

Окно START_EGM не закрывать: пока оно открыто, система работает. Вся база хранится в одном файле `data/egm.db`. Копия базы делается каждый день в `data/backups`, хранятся последние 30.

## Что внутри
| Было (Saby TMS / Excel) | Здесь |
|---|---|
| Заявки | Заявки: цена считается сама (прайс, цены клиента, зоны доставки), проверяются лимит и долг клиента |

| Мобильное приложение водителя | Telegram-бот и веб-приложение водителя: кнопки статусов, вес при погрузке и выгрузке, фото накладной, геопозиция |

| — | CRM: лиды (заявки из Telegram падают сюда сами), клиенты, объекты, договоры, задачи |
| — | Склад и закупки: карьеры, закупочные цены, остатки |
| — | Кабинет клиента: заказ, статусы рейсов, ТН, счета, долг, акт сверки |
| — | Отчёты: маржа по клиентам, материалам, машинам, водителям, карьерам; дебиторка по срокам; перерасход топлива |
| — | Роли: руководитель, диспетчер, менеджер, бухгалтер, механик, водитель, клиент. Журнал действий |

## Переход с текущих программ
Раздел «Настройки → Импорт из Excel». Скачиваете шаблон, вставляете данные из Excel или выгрузки Saby, жмёте «Проверить», потом «Загрузить».
Порядок: клиенты → объекты → номенклатура → цены → карьеры → техника → водители → открытые заявки.

## Подключение бота
1. В @BotFather создать бота и вставить токен в «Настройки → Компания и боты».
2. Если Telegram заблокирован, указать там же прокси.
3. В карточке водителя или клиента нажать «Подключить Telegram» и отправить человеку ссылку.

## Панель руководителя и голосовые заявки
- **Панель руководителя** (`#/owner`, открывается первой у директора): выручка, прогноз на конец месяца, маржа, «можно выставить сейчас», долги, светофор по машинам и менеджерам, крупный блок «Требует реакции» со ссылками. План месяца задаётся в «Компания и боты».
- **Утренняя сводка** в Telegram руководителю (по умолчанию в 8:00): подключить кнопкой «Мой Telegram» на панели. В боте команда `/svodka`.
- **Заявка голосом**: в системе (кнопка 🎙) или голосовым в бот. Речь распознаётся локально (faster-whisper, модель ~0,5 ГБ скачивается при первом использовании), аудио никуда не отправляется. Система делает черновик, заявка создаётся только после подтверждения человеком.
- Голосовое водителя в бот передаётся текстом диспетчеру.
- Тест: `python tests/owner_test.py http://localhost:8077 <пароль>` (17 проверок).
